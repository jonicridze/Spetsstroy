Конфиденциальность

Оператор обращений: ООО «Спецстройтехнологии». Адрес: 188516, Ленинградская область, Ломоносовский район, с. Русско-Высоцкое, ул. Промышленная, зд. 1, офис 35. Контакт по вопросам данных: info@spstech.ru.

Данные обращения

При заполнении формы вы передаёте указанные вами имя, компанию, телефон, email, описание проекта и приложенные документы. Эти данные используются для рассмотрения обращения и обратной связи.

Хранение и доступ

Обращения сохраняются на сервере. Доступ к ним и вложениям предоставляется только уполномоченным администраторам. Для административного входа используется необходимый сессионный cookie. Публичная часть не использует рекламные cookie; настройка анимации может сохраняться только на вашем устройстве.

Ваш запрос

Для уточнения, удаления данных или отзыва согласия свяжитесь с оператором по указанному email. Не прикладывайте документы, не относящиеся к обсуждаемому проекту. Сроки хранения определяются целью обращения и применимыми требованиями; организационный порядок должен быть утверждён оператором до начала приёма обращений.

Внешние сервисы

Шрифт загружается из Google Fonts. На странице контактов карта загружается с Яндекс Карт. На карте объектов используются OpenStreetMap и библиотека Leaflet. Эти сервисы получают стандартные технические сведения HTTP-запроса при загрузке их ресурсов. Отправка самой формы выполняется на сервер сайта.
